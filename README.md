# সালাত রিমাইন্ডার (Salat Reminder) 🕌

একটি দ্রুত, আধুনিক, লাইটওয়েট এবং সম্পূর্ণ বাংলা সালাত (নামাজ) রিমাইন্ডার ও ওয়াক্ত ট্র্যাকার ডেস্কটপ অ্যাপ্লিকেশন।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. 🕋 **সম্পূর্ণ বাংলা ইন্টারফেস (Full Bengali Interface)**:
   - ওয়াক্তের নাম (ফজর, যোহর, আসর, মাগরিব, এশা, তাহাজ্জুদ, সাহরি ও ইফতার)।
   - বাংলা সংখ্যা (০, ১, ২, ৩...) অথবা ইংরেজি সংখ্যা প্রদর্শনের টগল।
   - সকল বাটন, সেটিংস ও বার্তা সহজ ও স্পষ্ট বাংলায়।

2. ⏱️ **রিয়েল-টাইম লাইভ কাউন্টডাউন (Live Real-Time Countdown)**:
   - **বর্তমান ওয়াক্ত শেষ হতে কত সময় বাকি** তা সেকেন্ডসহ লাইভ ট্র্যাকিং।
   - **পরবর্তী ওয়াক্ত কখন শুরু হবে এবং শুরু হতে আর কত সময় বাকি** তা স্পষ্ট ডিসপ্লে।
   - ওয়াক্তের অগ্রগতি (Progress Bar) ভিজ্যুয়াল সূচক।

3. ⚠️ **নামাজের নিষিদ্ধ সময় সতর্কতা (Forbidden Times Alert)**:
   - সূর্যোদয়ের সময়, ঠিক দ্বিপ্রহরের সময় (জাওয়াল) এবং সূর্যাস্তের সময় নামাজ নিষিদ্ধের লাল/হলুদ সতর্কবার্তা।

4. 📍 **লোকেশন নির্বাচন (Location Selection)**:
   - **বাংলাদেশের সকল ৬৪ জেলা** (বিভাগ অনুযায়ী ফিল্টার ও নির্বাচন)।
   - আন্তর্জাতিক প্রধান শহরসমূহ (মক্কা, মদীনা, লন্ডন, নিউ ইয়র্ক, দুবাই ইত্যাদি)।
   - অটো জিপিএস লোকেশন ডিটেকশন ও কাস্টম অক্ষাংশ-দ্রাঘিমাংশ ইনপুট।

5. 🌐 **টাইমজোন সাপোর্ট (Timezone Selection)**:
   - ঢাকা (UTC+6), রিয়াদ/মক্কা (UTC+3), দুবাই (UTC+4), লন্ডন, নিউ ইয়র্কসহ বিশ্বের সকল গুরুত্বপূর্ণ টাইমজোন নির্বাচন সুবিধা।
   - ডিভাইসের সিস্টেম টাইমজোন স্বয়ংক্রিয় শনাক্তকরণ।

6. 📥 **সিস্টেম ট্রে সাপোর্ট (System Tray Background Mode)**:
   - অ্যাপটির ক্লোজ (✕) বাটনে ক্লিক করলেও অ্যাপ বন্ধ হবে না, উইন্ডোজ টাস্কবারের সিস্টেম ট্রেতে সচল থাকবে।
   - ট্রে আইকন টুলটিপ এবং রাইট-ক্লিক মেনুতে বর্তমান ও পরবর্তী ওয়াক্তের লাইভ আপডেট।
   - ট্রে আইকন থেকে তাৎক্ষণিক উইন্ডো ওপেন, সাউন্ড নিঃশব্দ বা অ্যাপ সম্পূর্ণ বন্ধ (Exit) করার সুবিধা।

7. 🔔 **স্মার্ট অ্যালার্ম ও আজান নোটিফিকেশন (Prayer Alarm & Sounds)**:
   - ওয়াক্তের শুরুতে মেলোডিয়াস আজান তাকবীর, মসজিদের ঘণ্টাধ্বনি, ইসলামিক চিম বা ডিজিটাল বিপ সুর।
   - ৫ মিনিট, ১০ মিনিট বা ১৫ মিনিট আগে অগ্রিম রিমাইন্ডার নোটিফিকেশন।
   - উইন্ডোজ নেটিভ ডেস্কটপ নোটিফিকেশন।
   - ওয়াক্ত অনুযায়ী আলাদা আলাদা অ্যালার্ম অন/অফ করার সুবিধা।
   - ৫ মিনিটের স্নুজ (Snooze) ও ইনস্ট্যান্ট স্টপ বোতাম।

8. 🧭 **কিবলা দিক নির্দেশক (Qibla Direction)**:
   - বর্তমান ভৌগোলিক অবস্থান অনুযায়ী কাবার সঠিক কম্পাস কোণ ও ডিগ্রি।

9. 📐 **ক্যালকুলেশন পদ্ধতি ও মাজহাব (Methods & Madhab)**:
   - ইসলামিক ফাউন্ডেশন বাংলাদেশ / করাচি (হানাফী)।
   - উম্মুল কুরা (মক্কা), মুসলিম ওয়ার্ল্ড লীগ, মিশর ইত্যাদি।
   - আসরের ওয়াক্তের হানাফী এবং শাফেঈ/মালেকী/হাম্বলী মাজহাব নির্বাচন।

## 🚀 ইন্সটলেশন ও রান করার নিয়ম (How to Run)

### পূর্বশর্ত:
- [Node.js](https://nodejs.org/) (সংস্করণ ১৮ বা তার বেশি)

### ১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/golam-mowla/salat-reminder.git
cd salat-reminder
```

### ২. ডিপেন্ডেন্সি ইন্সটল করুন:
```bash
npm install
```

### ৩. অ্যাপটি চালু করুন:
```bash
npm start
```

## 🛠️ ব্যবহৃত প্রযুক্তি (Tech Stack)
- **Framework**: Electron.js
- **Frontend**: HTML5, Modern CSS (Glassmorphism), Vanilla JavaScript
- **Calculations**: [adhan](https://github.com/batoulapps/adhan-js)
- **Audio Engine**: Web Audio API (Synthesized resonant tones & melody)
- **Typography**: Hind Siliguri (Google Fonts)
