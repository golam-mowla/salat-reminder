# সালাত রিমাইন্ডার (Salat Reminder) 🕌

একটি দ্রুত, আধুনিক এবং সম্পূর্ণ বাংলা সালাত (নামাজ) রিমাইন্ডার ও ওয়াক্ত ট্র্যাকার ডেস্কটপ অ্যাপ।

## বৈশিষ্ট্যসমূহ (Features)
- 🕋 **সম্পূর্ণ বাংলা ইন্টারফেস**: ওয়াক্তের নাম, সময়, কাউন্টডাউন এবং সেটিংস সম্পূর্ণ বাংলায়।
- ⏱️ **রিয়েল-টাইম লাইভ কাউন্টডাউন**: বর্তমান ওয়াক্ত শেষ হতে কত সময় বাকি এবং পরবর্তী ওয়াক্ত কখন শুরু হবে তা সেকেন্ডসহ দৃশ্যমান।
- 📍 **লোকেশন নির্বাচন**: বাংলাদেশের সকল ৬৪ জেলা এবং বিশ্বব্যাপী কাস্টম জিপিএস/শহর নির্বাচনের সুবিধা।
- 🌐 **টাইমজোন সাপোর্ট**: প্রয়োজন অনুযায়ী টাইমজোন পরিবর্তনের সুবিধা।
- 🔔 **অ্যালার্ম ও আজান নোটিফিকেশন**: প্রতিটি ওয়াক্তের শুরুতে সাউন্ড অ্যালার্ম এবং উইন্ডোজ নোটিফিকেশন।
- 📥 **সিস্টেম ট্রে সাপোর্ট**: অ্যাপটি ক্লোজ বা মিনিমাইজ করলেও ব্যাকগ্রাউন্ডে সিস্টেম ট্রেতে সচল থাকে।
- ⚡ **লাইটওয়েট ও সুপার ফাস্ট**: আধুনিক গ্লাস মরফিক ডার্ক/লাইট ইন্টারফেস।

## প্রযুক্তি (Built With)
- Electron.js
- HTML5 / Modern CSS / Vanilla JavaScript
- Adhan Library
